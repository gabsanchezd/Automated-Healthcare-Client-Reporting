# Automated Healthcare Client Reporting System

An end-to-end healthcare reporting automation project built using:

- Microsoft Excel
- Power Query
- VBA
- PivotTables
- Data Validation
- Automated Client Reporting

## Project Overview

This project simulates a healthcare revenue-cycle reporting environment using synthetic claims data across multiple fictional healthcare entities.

The system is designed to automate data ingestion, transformation, validation, analysis, and generation of recurring client reports.
